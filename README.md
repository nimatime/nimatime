Building [Axint](https://github.com/agenticempire/axint), the proof layer for AI-written Swift.

Your AI writes Swift. Axint makes sure it ships: Xcode-backed verdicts, signed receipts, and a GitHub Action that gates merges on whether the code actually builds and the tests actually pass.

- [agenticempire/axint](https://github.com/agenticempire/axint) - prove AI-written Swift before merge
- [axint-examples](https://github.com/agenticempire/axint-examples) - examples for the proof and repair layer
